# EZ Zoom Support

Thank you for using **EZ Zoom – Mouse Magnifier**.

## Quick help

### Hold-key zoom does not start

1. Click the EZ Zoom toolbar icon.
2. Confirm that **Enable hold-key zoom** is turned on.
3. Confirm the selected hold key: Ctrl, Alt, Shift, or Cmd/Win.
4. Refresh any webpage that was already open when EZ Zoom was installed or updated.
5. Test on a normal `https://` webpage.

Chrome does not allow extensions to modify protected pages such as `chrome://` pages or the Chrome Web Store itself.

### Keyboard shortcuts do not work

1. Open `chrome://extensions/shortcuts`.
2. Find **EZ Zoom – Mouse Magnifier**.
3. Check that the desired shortcuts are assigned and do not conflict with another extension or operating-system shortcut.

Default shortcuts:

| Action | Shortcut |
|---|---|
| Zoom in | `Alt + Shift + Up` |
| Zoom out | `Alt + Shift + Down` |
| Reset zoom | `Alt + Shift + X` |

### EZ Zoom does not work in Incognito mode

Open `chrome://extensions`, select **EZ Zoom – Mouse Magnifier**, and enable **Allow in Incognito**. Chrome leaves this permission disabled by default.

### A particular website behaves incorrectly

Some webpages use unusual transforms, fullscreen layers, canvas rendering, or application-specific keyboard handling. Please submit a bug report and include the affected URL when it is safe to share.

## Report a problem

[Open a bug report](https://github.com/reza-ghazi/ez-zoom/issues/new?template=bug_report.yml)

Please include:

- EZ Zoom version;
- Chrome version;
- operating system;
- affected webpage, if safe to share;
- zoom method used;
- exact reproduction steps;
- expected and actual behavior.

Do not include passwords, authentication codes, private page content, or other sensitive information in a public issue.
